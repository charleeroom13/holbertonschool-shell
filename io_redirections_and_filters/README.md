# io_redirections_and_filters

- 0-hello_world: prints "Hello, World" to standard output.
- 1-confused_smiley: "(Ôo)'.
- 2-hellofile: displays content of  "/etc/passwd" file.
- 3-twofiles: displays content of "/etc/passwd" and "/etc/hosts".
- 4-lastlines: displays last 10 lines of "/etc/passwd".
- 5-firstlines: displays first 10 lines of "/etc/passwd".
- 6-third_line: displays 3rd line of file "iacta"
- 7-file: (-_-)
- 8-cwd_state: writes result of "ls -la" into file "ls_cwd_content", overwriting it if it exists and creating it if it doesn't.
- 9-duplicate_last_line: duplicates last line of file "iacta"
- 10-no_more_js: deletes all regular files (not dirs) with a ".js" extension in current dir and all its subfolders.
- 11-directories: counts number of dirs and subdirs in current dir, incl. hidden ones and excluding "." and ".."
- 12-newest_files: displays 10 newest files in current dir, one per line, from newest to oldest.
- 13-unique: takes a list of words as input (one per line) and prints, sorted, only the words that appear exactly once.
- 14-findthatword: displays lines containing pattern "root" from file "/etc/passwd"
- 15-countthatword: displays (count) number of lines that contain the pattern "bin" in file "/etc/passwd"
- 16-whatsnext: displays lines containing pattern "root" and 3 lines after them in file "/etc/passwd"
