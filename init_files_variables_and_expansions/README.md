# init_files_variables_and_expansions

- 0-alias: creates an alias named "ls" with the value "rm -f *"
- 1-hello_you: prints "hello" followed by current user.
- 2-path: adds "/action" to the end of "PATH"
- 3-paths: counts number of dirs in "PATH"
- 4-global_variables: lists all environment variables.
- 5-local_variables: lists all local variables, environment variables and functions.
- 6-create_local_variable: creates a new local variable "BEST" with value "School"
